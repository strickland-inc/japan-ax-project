# 勉強会の資料

勉強会で使った資料を、1 回につき 1 フォルダで置きます。

## 置き方

```
studies/
└─ 01_回の名前/
   ├─ index.html     スライドや資料の本体
   ├─ slides.pdf     PDF 版
   └─ images/        使った画像
```

- フォルダ名は、開催順の番号と回の名前をアンダースコアでつなぎます。
- 第三者の画像や素材を使ったら、[CREDITS.md](../CREDITS.md) に出所とライセンスを 1 行足します。
- 新潟だけで開いた勉強会は、`studies/niigata/` の下に同じ形で置きます。
