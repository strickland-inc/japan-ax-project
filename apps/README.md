## keiri-app

見積書・請求書の作成から、経費の記録、会計帳簿、決算の準備までを 1 つにまとめた経理アプリです。データは自分の Google スプレッドシートに保存され、Cloudflare Workers で動きます。

- **何が要るか。** Google のアカウント、Cloudflare のアカウント、Gemini の API キー（AI 機能を使う場合）です。
- **導入の仕方。** [README](https://github.com/strickland-inc/keiri-app#readme) に、Claude Code や Codex に渡せば導入を進めてくれる文章があります。エンジニアでなくても、アカウントの作成とログインだけで進められる作りです。
- **費用。** アプリは無料です。Cloudflare の無料プランでは CPU の上限が足りず、続けて開くと一部の表示が失敗することがあります。有料プラン（月 5 米ドルから）が必要になる場合があります。詳しくは README の「無料プランの制約と料金」を見てください。
- **ライセンス。** MIT です。商用利用も改変もできます。

使ってみた感想や、導入で困ったことは、keiri-app の [Issue](https://github.com/strickland-inc/keiri-app/issues) に書いてください。自治体や事業者での使い方は、このリポジトリの [cases/](../cases/) に事例として載せられます。
